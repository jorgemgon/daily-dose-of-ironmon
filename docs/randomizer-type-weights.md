# Daily Dose randomizer — type weights

Type biases are event modifiers applied inside `SpeciesWeights`: for every bias entry, a species
whose primary or secondary type matches gets its pick weight multiplied by the factor.

Scope controls where the bias applies:

- `lab` — starter selection only.
- `early` — Route 1, Route 2, Route 22, Viridian City and Viridian Forest wild encounters only.
- `all` — both.

Starter selection passes `lab=true`, so a bias with `--type-bias-scope early` does **not** affect
starters; use `lab` or `all` for event starters.

## Example: lab bias GHOST x4, FIRE x0.5

Command:

```powershell
java -Xmx2G -cp build\classes com.dabomstew.pkrandom.ddoz.DdozReport `
  <vanilla.gba> <faster-firered-1.2.ips> <outdir> `
  --bias GHOST=4 --bias FIRE=0.5 --scope lab 0 1 2 42 4242
```

## Effect on starter frequency

`--probe --type ghost` over seeds `0..39` (starter draws only, weights `daily-v1`):

| Configuration | Seeds with a Ghost starter |
|---|---:|
| neutral (no bias) | 3 / 40 |
| `GHOST x10`, scope `lab` | 20 / 40 |
